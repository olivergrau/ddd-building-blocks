# DDD.BuildingBlocks

DDD.BuildingBlocks provides reusable tactical Domain-Driven Design and event-sourcing building blocks for .NET applications.

Version 2.1.1 targets .NET 10 and provides stable aggregate and event identities, complete commit metadata, event-store providers, projections, recovery, snapshots, and a MkDocs-based user-documentation site for event-sourced applications.

User documentation, package-specific usage, the complete 1.x-to-2.0 change inventory, and migration guidance are maintained at <https://github.com/olivergrau/ddd-building-blocks/tree/main/docs>.

Packages are distributed through GitHub Release assets and are not published to a public NuGet registry.
